# 결함 탐지(Defect Detect)

https://xilinx.github.io/kria-apps-docs/kv260/2022.1/build/html/docs/defect-detect/defectdetect_landing.html

'결함 탐지(Defect Detection)' 가속 애플리케이션은 컴퓨터 비전 라이브러리 함수를 사용하여 고속 공장 생산 라인에서 망고의 결함을 자동으로 탐지하고 분류하는 머신 비전 애플리케이션입니다.

> 참고
> 테스트용 망고 이미지는 COFILAB 사이트에서 가져온 것입니다.

## 개요

* 소개

## 기능

* 실시간 카메라 소스 또는 파일 소스로부터의 흑백(모노크롬) 이미지 처리
* 망고 결함 탐지 및 분류
* 다양한 처리 단계에서의 HDMI 또는 DisplayPort 출력 지원
* 사용자 프로그래밍 가능한 컴퓨터 비전(CV) 모델
