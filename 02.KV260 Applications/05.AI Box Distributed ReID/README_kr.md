# AI Box 분산형 재식별(ReID)

https://xilinx.github.io/kria-apps-docs/kv260/2022.1/build/html/docs/aibox/aibox-dist_landing.html

AIBox 분산형(Distributed) 가속 애플리케이션은 분산되고 확장 가능한 다중 스트림 교차 추적(cross-tracking) 및 재식별(Re-Identification, ReID) 기능을 수행합니다. 이 애플리케이션은 머신 러닝을 활용하여 보행자를 추적하고, 여러 카메라 스트림을 디코딩하며, 다양한 카메라 피드 전반에 걸쳐 보행자를 탐지하고 추적합니다. 주요 활용 분야로는 스마트 시티, 소매 분석, 영상 분석 등이 있습니다.

## 개요

* 소개
* 다음 단계
* 참고 자료

## 기능

* IP 카메라로부터 최대 4개의 입력 스트림 지원
* 1080p 해상도의 H.264/H.265 디코딩 기능
* 개별 스트림에서의 보행자 탐지 및 추적
* HDMI 또는 DisplayPort 출력 지원
* 사용자 프로그래밍 가능한 딥러닝 모델

## 빠른 시작(Quick Start)

* 보드 설정 및 애플리케이션 배포
